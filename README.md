ThermoPlanner AI
Autonomous Microclimate Mitigation & Financial ROI Engine
Built for FortyGuard Hackathon '26

Executive Overview
ThermoPlanner AI bridges FortyGuard's 2-meter resolution surface and air temperature intelligence with predictive machine learning and agentic decision logic. It automatically detects micro-heat zones, quantifies HVAC energy financial penalties, and outputs actionable, high-ROI urban mitigation blueprints.

Key Features
- FortyGuard 2-Meter Integration: Ingests high-resolution microclimate surface and air temperature layers.
- ML HVAC Burden Predictor: Multi-variable model predicting yearly cooling expense surges ($/sq.ft/yr).
- Agentic Mitigation Engine: Autonomous recommendation system prioritizing targeted cooling interventions based on payback period (months).
- Command Dashboard: Built with an Obsidian Dark aesthetic, 3D tilt interaction elements, live geospatial heatmaps (Leaflet.js), and dynamic financial analytics charts (Chart.js).

Setup Guide
1. Run backend: python app.py inside backend folder.
2. Open index.html in browser.
